# DJI_FCC_GPSOFF

[English](README.md) · **Русский**

Android-приложение для **пультов DJI с экраном — RC 2 (RM331) и RC (RM330)**.

Общается с дроном по **DUML** через собственный loopback TCP-прокси пульта — без USB, без AOA, без root.
Проверено на железе: **DJI RC 2 (Android 11) + Lito X1**.

![Страница «Передача» в DJI Fly после Apply FCC — доступны 5,8 ГГц и двухполосный режим, поверх неё ручка ≡ плавающего меню](screens/fly-transmission-5.8ghz-overlay.png)

## Что умеет

- **Мощность FCC + частоты 5.8 ГГц / двухполосный режим.** Применяется вживую, без перезагрузки.
- **Автозапуск вместе с пультом и автоматическая активация FCC** — сервис поднимается при загрузке,
  дожидается линка и переприменяет FCC после каждого релинка (DJI Fly возвращает CE).
- **Переключатели, в том числе через плавающее меню поверх DJI Fly** — GPS, передние LED, режим полёта
  ATTI/Cine. Меню — маленькая кнопка-ручка ≡ поверх Fly; тумблеры срабатывают, не сворачивая Fly и не
  прерывая полётную сессию.
- **Редактор параметров.** Параметры адресуются **по хешу имени, а не по id параметра**: имена редко меняются
  при обновлении прошивки и часто совпадают у разных моделей, а индексы — нет. На одном и том же борту
  `ce_country_type` стоял под индексом 239 на одной прошивке и 49 на следующей, а имя не сдвинулось.
  Перед правкой приложение спрашивает описание параметра **у самого борта** (`03:F7`) — поэтому диапазон,
  ширина и значение по умолчанию берутся из прошивки, которая перед вами, а не из файла, и **сброс
  возвращает заводское значение борта** (`03:FA`), а не то, что о нём думает список.
- **Три источника списка параметров.** Наборы для 10 моделей **зашиты в APK**; экспорт **dronehack**
  загружается файлом (v1 `.dhp` или v2 `.dhv2params`, примеры в [`params_example/`](params_example/));
  либо приложение **читает весь каталог прямо с борта по радио** примерно за две минуты — для аппарата,
  которого нет в наборах. Список от *другой* модели безопасен в любом случае: неизвестное имя просто не
  прочитается и не запишется, и теперь приложение говорит об этом прямо, а не оставляет вас с молчащим
  чтением. На тестовом борту в зашитом списке нашлись 94 имени, которых в прошивке нет, и не хватило 22,
  которые есть — такое расхождение может разрешить только сам аппарат.
- **Проверка обновлений** через релизы GitHub — отключаемая, предварительные релизы по желанию;
  показывает описание релиза и ставит APK после подтверждения.
- **Интерфейс на русском или английском**, переключается внутри приложения и не зависит от системного
  языка пульта.
- **Веб-дашборд** для браузера в той же сети — редактор параметров, дублирование функций приложения, записи
  экрана, загрузка логов полётов, захват трафика в `.pcap` (Wireshark), raw-запросы DUML.

## Установка

Скачайте APK со страницы [Releases](https://github.com/lmdegreeds/dji_fcc_gpsoff/releases) и установите
**на пульт** (скопируйте по MTP или откройте ссылку в браузере пульта). Android один раз спросит разрешение
на установку из этого источника.

Все релизы подписаны ключом проекта. APK из другого места или собранный самостоятельно debug-сборкой
**не встанет поверх** установленного — Android не принимает смену подписи. Если переходите на другую
сборку, сначала удалите старую.

## Первый запуск

Открывается **мастер настройки**. По каждому разрешению он объясняет, зачем оно нужно и что именно нажать на
открывшемся системном экране, а в конце спрашивает, какие сервисы запустить сразу и какие добавить в
автозапуск:

| Шаг | | |
| --- | --- | --- |
| **Спец. возможности** | рекомендуется | Закрывает гейтом каждое чтение с видео-порта DJI Fly, чтобы оно не могло дёрнуть картинку, и считывает модель дрона с экрана Fly |
| **Установка приложений** | необязательно | Позволяет приложению ставить собственные обновления |
| **Логи и записи экрана** | необязательно | Доступ к папкам для страниц логов и видео в веб-дашборде |
| **Сервисы** | — | Авто-FCC, плавающее меню, веб-дашборд: «Сейчас» и «Автозапуск» задаются отдельно |

Всё после первой страницы можно пропустить — приложение работает и когда все необязательные разрешения
отклонены, честно показывая в интерфейсе, что при этом хуже. Язык переключается в шапке мастера, а сам
мастер можно открыть заново из меню ⋮.

## Как пользоваться

1. Включите дрон и дождитесь живого линка в DJI Fly.
2. Приложение само опрашивает, на какой вариант написания параметров отвечает дрон, и выставляет **профиль
   устройства** — *Lito X1* (короткие имена) или *Other DJI* (`g_config.*` / `c1_*`). Результат запоминается
   для каждого серийника. Профиль можно задать вручную на странице Services; неверный профиль делает
   regulatory-запись молча бесполезной.
3. Нажмите **⚡ Включить FCC** — или включите **Авто-FCC**, и keepalive применит его при каждом подключении.
4. Проверьте в DJI Fly → **Передача**: выбор диапазона и график мощности появляются сразу, без перезагрузки.
   Задержка применения — до ~20 с.

**Плавающее меню** — ручка ≡ поверх DJI Fly с тумблерами GPS / LED / режим полёта; срабатывают, не выходя из
Fly. Нужно разрешение «поверх других приложений».

**Редактор параметров** — возьмите список кнопкой **📂 Из файла** (экспорт dronehack `.dhp` / `.dhv2params`),
**📦 Из набора** (зашиты в APK) или **📡 С борта** (читает всю таблицу по радио, ~2 мин — сначала остановите
DJI Fly, он делит тот же порт). Дальше ищите, читайте и пишите по имени. В диалоге редактора есть строка
`список:` и строка `борт:`: при расхождении видно обе, а параметр, которого в прошивке нет, помечается прямо,
и запись со сбросом для него блокируются — вместо записи, которая уйдёт в никуда. **Сначала сделайте резервную копию параметров дрона в DJI Assistant 2 по USB**: отмены здесь нет, и
исходные значения — единственный путь назад.

**Веб-дашборд** — включите в приложении и откройте `http://<ip-пульта>:8899/` (URL показан на главном экране;
IP меняется после перезагрузки). `curl .../help` перечисляет все сырые эндпоинты. Биндится на `0.0.0.0:8899`
**без аутентификации** — отладочный инструмент для доверенной сети; выключайте, когда закончили.

**Обновления** — проверяются на GitHub при запуске (не чаще раза в 6 часов), если включено на странице
Services. Для новой версии открывается окно с описанием релиза; ничего не скачивается и не ставится без
подтверждения. Предварительные релизы предлагаются только если вы их включили.

> **Сборка только-FCC.** Restore CE убран намеренно — возврат к CE снимает 5.8 и требует перезагрузки дрона.
> Ассет `ce_restore.json` остался как справка, приложение его не проигрывает.

## Как это работает

Три loopback-прокси DUML на `127.0.0.1`, все **многоклиентские** — DJI Fly держит свою сессию, так что
перехватывать ничего не нужно. **40009** (RADIO/SDR) несёт FCC и 4G; **40008** — записи параметров;
**40007** — видео-зеркало FPV для DJI Fly: приложение **никогда в него не пишет** и закрывает гейтом каждое
чтение оттуда, потому что сокет на нём замораживает видео Fly на ~1–2 с.

Apply FCC проигрывает последовательность из 21 кадра на 40009, ядро которой — две записи **SDR-регистров**
(`0xffff0048` = 2 = `setForceFcc`, `0xffff0063` = 3), плюс кадры региона/страны и regulatory-запись параметра
в написании текущего профиля. Параметры адресуются рантайм-хешем их **имени**, никогда не индексом. Плавающее
меню может менять параметры в полёте потому, что оно не отбирает передний план у DJI Fly, а его записи идут в
порты, за которыми Fly не следит.

accessibility, определение серийника и модели, доступ к логам — в
[`doc/PROTOCOL.ru.md`](doc/PROTOCOL.ru.md).**


## Статус

Проверено на железе: Apply FCC (мощность **и** 5.8 / двухполосный, вживую, прошивки v300 и v400);
авто-применение и восстановление после релинка; карта портов; записи GPS / LED / режима; чтение серийника и
детекция линка; чтение метаданных параметра и сброс к заводскому значению прямо с борта; полный обход таблицы
на 1594 слота (дважды, с одинаковым результатом). *Чтения* параметров **возвращаются** — но только маршрутом
wrapped 40007 и примерно в 70% одиночных окон при DJI Fly в фоне, поэтому каждое чтение делает повторы.
Проверено не полностью: 4G (нужен Cellular Dongle); имена параметров не-Lito.
